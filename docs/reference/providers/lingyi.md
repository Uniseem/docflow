# 零一万物（01.AI / Yi）——已停止服务

> 查证日期 2026-09-23。数值以官方页面为准，来源见文末编号。

## 概览

- 李开复创立，Yi 系列（yi-lightning、yi-large、yi-medium-200k 等），OpenAI 兼容 API，`https://api.lingyiwanwu.com/v1`。
- **平台已关停**（官方公告，经 IT之家报道）：即日起（2026-08-10 公告）停止新用户注册及充值；**2026-09-03 24:00 起停止模型体验、API 调用及相关服务**；余额退款窗口开放至 2026-12-03。[1]
- 查证日（2026-09-23）API 已停止 20 天，平台实质上不可用。公司转向企业级解决方案（政企定制），消费级开放平台不再运营。[1][2]
