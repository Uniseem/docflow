# 智谱 AI（GLM / BigModel）

> 查证日期 2026-09-23。数值以官方页面为准，来源见文末编号。

## 概览

- 清华系，GLM 系列。现行旗舰 `glm-5.3` / `glm-5.3-flash`（1M 上下文），向下有 GLM-5.2 / 5.1 / GLM-4.7 等；免费层两款：`glm-4.7-flash`（文本，200K 上下文，输入/输出/缓存全免费）、`glm-4.6v-flash`（视觉）。[1]
- 国内站 open.bigmodel.cn，人民币计价；需实名认证才有免费调用权限。[2]
- **有一个订阅套餐：Coding Plan**（编码工具向，OpenAI/Anthropic 兼容端点，docs.bigmodel.cn/cn/coding-plan），有 Lite/Pro 档和 5 小时/周/月三级限额（社区报告 2026 年初有过额度争议与致歉）。[3][4]

## 模型

- GLM 4.x 起支持 Thinking Mode；5.x 默认行为未查到明确「默认开/关」表述 → 以模型页为准。
- 免费 `glm-4.7-flash` 支持 200K 上下文、Thinking、Function Calling，但**并发只有 1**（官方限 1 并发，社区一致确认）；GLM-4-Flash 系免费档并发 3~10。[2][5]
- 温度/采样：未查到按场景推荐表；OpenAI 兼容参数透传。

## 限流与档位

### 按量 API

- **限速不公开统一数值**：官方速率限制文档未给统一 RPM/TPM 表，需登录控制台「速率限制」页查看本账号额度；触发限流返回 1302、平台过载返回 1305；可申请提并发（社区称约 10 个工作日审核）。[2][5]
- 社区实测口径（非官方）：免费层基础 QPS=2（高峰可能降到 1），付费层按模型单独设限速。[5][6]
- **模型会下线**：GLM-4.5-Flash 已于 2026-01-30 下线并自动路由到 GLM-4.7-Flash——不要写死模型 ID。[2]

### 订阅套餐

Coding Plan 见前文（不建议做翻译预设）。

| 错误分类注意 | 智谱用 1302/1305 业务码表达限流，HTTP 层可能是 200 带错误体或 4xx，DocFlow「HTTP 200 但正文含 error 对象」的预检正好覆盖这种网关行为。 | [2] |

风险提示：

1. **免费≠生产可用**：glm-4.7-flash 并发 1、长文档超 8K 降速明显（社区称降至约 1% 速度），只适合体验不适合批量翻译。[5][6]
2. **限速黑盒**：无公开数值表，429/1302 只能靠自适应降并发；提额审核周期长。[2][5]
3. **Coding Plan 争议**：2026 年初套餐额度规则透明度被官方致歉过，即使用户问到也要建议按量 API 更稳。[4]
4. **模型换代快**：4.5-Flash 说下线就下线且自动改路由，账单模型可能对不上预期。[2]
