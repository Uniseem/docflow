# 2026-09-22 M2 PDF 解析

## 会话 1（Cursor Grok 4.6）

### 目标

M2-1 到 M2-9：fixture、inspect、字形到段落、表单、analyze worker、调试脚本。

### 做了什么

- `scripts/make-fixtures.mjs` 生成 08.2 全部合成 PDF（每个 < 200 KB）；`cid-font.pdf` 用 `@cantoo/fontkit` 子集化 Noto Sans SC。真实论文 `arxiv-2201.11903.pdf`（CoT，CC-BY-4.0）与 `arxiv-2302.13971.pdf`（LLaMA，CC-BY-4.0）。
- `inspectPdf`：加密 / 扫描 / 空页 / 无效头 / 正常单栏。
- `glyphs.ts`：pdf.js 算子流；`Trm = CTM × Tm × Tfs`（左乘 Tfs 会把用户空间平移再缩放一次）；`setTextMatrix` 的参数是包了一层的 `Float32Array`。
- 行/栏/公式/段落/规整、pdf-lib 表单引用（Form 是 `PDFRawStream.dict`，不是 `PDFDict`）。
- `PdfWorkerHost` + `tests/unit/hang-worker.mjs` 验证超时 terminate 与取消。
- `scripts/analyze-pdf.mjs` 用 `tsx` 跑（规划写 `node`，脚本要 import TypeScript 源码）。

### 没做成 / 坑

- Node 必须用 `pdfjs-dist/legacy/build/pdf.mjs`，否则 `getDocument` 失败并被收成 `pdf_open`。文档代理没有 `destroy`，用 `cleanup`。
- Symbol 字体 `ascent`/`descent` 为 NaN，写入段落 bbox 会让 zod 拒绝；回退 0.8 / −0.2。
- two-column 快照级栏检测未单独断言分界坐标，只断言页数与段数。
