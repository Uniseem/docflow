### 没做成 / 坑

- 子代理在核对时发现的代码问题（本次只改文档，没有修）。标 ✔ 的已在本会话复核，其余是子代理读代码得出、尚未复核：
  - ✔ `pipeline/run.ts` 的 `bundledFonts()` 用 `process.resourcesPath` 判断，`npm run dev` 下指向 Electron 自带的 Resources，写回找不到字体；应改用 `app.isPackaged`。
  - ✔ `session.logsDir` 取的是 `configureLogger()` 返回的 `logs/main.log` 文件路径：`shell:openLogs` 对它 `mkdir` 会失败（「打开日志」按钮不可用），`app:info.logsDir` 也是文件路径。
  - ✔ `pipeline/hooks.ts` 调 `analyzeStage` 时页数写死为 1，analyze 超时永远按 1 页算。
  - `glyphs.ts` / `content-walker.ts`：`Tm` 带缩放（`1 Tf` + `10 0 0 10 … Tm`）或 CTM 缩放 ≠ 1 时字形前进量算错（子代理实测 `Hello` 宽 2.3 pt，应为 22.8）。影响大，优先复核。
  - 所有文档共用一个 PDF worker：取消或超时一份文档会让其他文档正在跑的请求变成 `worker_crashed`。
  - 公式字体别名 `DFo<n>` 每页从 1 编号，页面共用或继承 `/Resources` 时后面的页覆盖前面的。
  - 编码失败时表单流已写回：表单里的原文被删、译文没写。
  - 公式颜色之后不重置，同段后面的中文沿用公式颜色；共享表单里的嵌套表单没有排除。
  - 翻译：服务长时间不可用时以永久失败 `mostly_untranslated` 结束而不是可重试；`submit()` 不看 `retryable`，oversized/refused 也要退避约 95 s；网络错误显示英文 `TypeError: fetch failed`；200 带 error 正文一律重试（含 Key 无效）；`normalizeMarkers` 吞掉 `{vN}` 两侧空格；无 Key 的 anthropic 请求缺 `anthropic-version`；listModels 遇 401/网络错误只显示内部错误；第 8 次失败仍提示「n 秒后重试」；缓存写失败不记日志。
  - 界面与事件：bundle 导出没记入 `exportedPaths`，「打开所在文件夹」报 not_found；`op_mismatch`、`encode_failed`、verify 等部分处理记录是英文；「第 Q 段」显示内部段落 id；macOS 没有窗口时不发系统通知；错误边界的「重新启动」只能 reload；新建翻译的文件大小检查不会触发，主进程也不拒绝 0 字节 PDF。
  - 打包与测试：`pdfjs/{cmaps,standard_fonts}` extraResources（约 2.4 MB）没有被读取；`release.yml` 手动触发在分支上会因标签检查失败；`ci.yml` 头注释过时；`THIRD_PARTY_NOTICES` 列出了已排除的 `@napi-rs/canvas`；mock 的 Anthropic `claude-mock*` 聊天返回 404、Azure 总是 401；`compose.test` 用例名写 15 s 实际上限 30 s。
