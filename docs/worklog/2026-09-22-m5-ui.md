### 没做成 / 坑

- **打包产物必须跟 renderer 同步。** Playwright 打的是 `release/`，不是源码。加了 `data-testid="document-row-*"` 之后若未重打 `--dir`，产物里搜不到该字符串，列表定位全失败。
- **`documents:create` 成功但列表行不出现。** 最新 `createDocument` 能拿到 `created[0].id`（主进程已入库），但 15 s 内 `document-row-*` 计数仍为 0。`handleDocumentsCreate` 本身不 `send('document:changed')`，只靠调度器 `onChanged` 节流 200 ms 推送。新建翻译弹窗会在成功后 `list()`，E2E 直连 IPC 没有这一步。下一步应：create 后立即推送 `document:changed`，E2E 改完后重打 `--dir` 再跑。
- **HeroUI 3 不适合 `getByRole('button')`。** 多数 `Button` 没有 `role="button"`，也不转发 `data-testid` / `aria-label`。用 `getByText`。侧栏筛选文案「已完成」始终存在，不能当翻译完成判定；用 `data-status`。
- **`first-run.spec`：** 能进设置、点「添加服务商」，超时在 DeepSeek 菜单项（Dropdown 弹出层）。`data-testid="add-provider"` 包在 Dropdown 外，是否进产物同样取决于是否重打。
- **`dfapp://`：** 自定义协议加载 renderer 未解决 module 脚本；生产改走 `loadFile` + 内联。协议代码与单测仍在，可后续删。
