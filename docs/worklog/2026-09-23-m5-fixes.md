**M5-8 真实论文版面**（ResNet、BERT、Attention、CoT、LLaMA 五篇，`tmp/` 下用伪中文假译文跑 analyze→compose→verify，再用 MuPDF 渲染逐页看）

- **每个写回页的内容流都混入了压缩字节**：pdf-lib 的 `normalize()` 给页面包了 `q`/`Q` 两个自建流，`getContents()` 返回的是 Flate 压缩后的字节，被当作内容流拼了进去。pdf.js 容忍，MuPDF 每页报语法错误（其他阅读器可能显示异常）。`compose/streams.ts` 对 pdf-lib 自建流改用 `getUnencodedContents()`。
- **间接 `/Length` 的流被截掉最后一个字节**：pdf-lib 解析时解不开间接长度，只能扫描 `endstream`，会把数据末尾真实的 `\r` 当换行删掉（BERT 的 6 个图片 SMask 损坏）。新增 `pdf/load-pdf-lib.ts`：加载前把能解析的 `/Length n g R` 原位替换为数字（等长补空格，偏移不变）。
- **两栏检测几乎总是失败**：分界取了「左栏左边界后的第一个空 bin」（x≈70），所有行被判到右栏，左右栏逐行交错，真实论文几乎每行自成一段（ResNet 1523 行→1424 段）。改为：峰值连同相邻 bin 计数；在「左栏行都已开始」到「右栏第一行开始」之间找横跨最少的最宽区间，取中点；非公式行只要横跨分界就算通栏；一栏被整幅图占满的页面沿用前页的分界。
- **斜体整句被当成公式**：TeX 输出没有空格字形，`italicProse()` 拼字不补空格，整行只算 1 个单词。改为按字距断词。
- **图内文字被翻译**：`short_isolated` 用段落自身宽度当栏宽，规则从未生效；「附近有正文」不看水平位置。改为真实栏宽、上下两遍判定（含同一行左右相邻），以句号结尾且 ≥3 词的短句算正文；新增 `small_text`：小于 0.75 × 正文字号且不是标题/图注/脚注的文字视为图表内部（新常量 `FIGURE_TEXT_RATIO`）。
- **正文字号按单页估计**：图多的页面小字比正文多，正文全被判成标题。段落层改用全文档到本页为止按字符计的字号众数。
- **文字环绕图的单栏页**：按基线排序时正文行与图内文字交替出现，正文逐行成段。段落合并改为向前最多看 6 个草稿，跳过与当前行 x 不重叠的旁侧内容。
- **本机服务（Ollama、LM Studio）从来翻译不了**：界面认为无需 Key 即已配置，但并发池一律报「未配置 API Key」。池对 `keyOptional` 的服务商不带 Key 直接请求。
