- eslint 配置 `import js from '@eslint/js'`，eslint 10 不把它当直接依赖装上。补 `@eslint/js@^10`。
- `dist` / `dist:dir` 改为 `npm run build && electron-builder …`，让 `prebuild` 生成 `THIRD_PARTY_NOTICES.md`。
- type-checked ESLint 对 `.mjs` / `eslint.config.js` 关掉；`tsconfig.node.json` 增加 `vitest.config.ts`、`playwright.config.ts`、`allowJs`。
