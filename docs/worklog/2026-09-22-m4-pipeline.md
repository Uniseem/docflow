# 2026-09-22 M4 流水线、文档库、IPC

## 会话 1（Cursor Grok 4.6，16:26）

### 目标

M4-1 到 M4-6：文档库、调度器、pipeline、IPC、协议/菜单/通知，冒烟写出中文 PDF 与双语 PDF。

### 做了什么

- 文档库：`manifest` / `events`（串行 append、超量截断保留首条）、索引筛选、复制源文件、fflate ZIP 导出。
- 调度器：并发上限、可重试失败按 20×attempts 秒退避、取消 abort、启动时 `processing/retrying → queued`。pipeline 在进入阶段前检查 `signal.aborted`，避免取消发生在首次 `update` 期间导致任务挂死。
- `pipeline/run.ts`：inspect/analyze 断点、事件文案、compose/verify、归档到 `output/` 后删除 `work/`。
- IPC：`src/shared/ipc.ts` 通道表、`ipc/register.ts` 信封、`handlers` 注入 library/scheduler；preload `invoke`/`on`/`pathsForFiles`。
- `docflow://library/…` 只解析库内 `.pdf`（拒绝 `..`，realpath 防符号链接逃逸）；中文菜单 DocFlow/文件/编辑/窗口/帮助；完成后台通知与 Dock 徽标。
- 主进程启动：打开文档库、假服务商注入（`DOCFLOW_FAKE_PROVIDERS=1`）、worker、调度器、协议、IPC。

### 怎么验证的

- `npm run check`：通过（161+ 单测，含本次新增）。
- `documents:*` 每个通道至少一次 handler 单测（create/list/get/events/rename/retry/cancel/delete/export/reveal/openExternal）。
- 冒烟：`documents:create` + 真 pipeline（假翻译前缀「译」）跑 `tests/fixtures/colored-text.pdf`，`output/mono.pdf` 与 `output/dual.pdf` 出现，状态 `completed`。
- 协议单测：越界 `..` 与非 PDF 返回空。

### 没做成 / 坑

- Zod `.strict()` 下不能把 `settingsSnapshot: undefined` 塞进 `DocumentSummary`，必须删掉该键。
- macOS `/var` → `/private/var`，协议解析结果要用 `realpath` 比较。
- 搜索「alpha」会命中 `originalFilename`，两个文档若都从 `alpha.pdf` 复制就会都命中；测试改为不同文件名。
- 未在本会话里实际点开 `npm run dev` 的 DevTools 手跑 invoke；Electron 主进程已接线，自动化冒烟走同一套 `documents:create` handler。界面仍是 M0 空壳，M5 再补。
